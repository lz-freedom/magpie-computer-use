MCU

让 Agent 通过本机 ChatGPT Computer Use 操作 macOS 应用。调用 Computer Use 时，任务交给这里选择的模型执行，Agent 收到事实报告和证据截图，自己下结论。

提供给 Agent 的工具
详情
1
Agent 拿到两套工具
委托工具 computer_use、look、list_computer_use_models，加上 ChatGPT 原版的直接操作工具 js / js_reset。
2
调用 computer_use 时按“只用委托”进行
由下面设置的执行模型操作，交回事实报告和证据截图，Agent 自己下结论。
3
自己调用操作工具时按“只用直接操作”进行
由 Agent 自己的模型一步步操作，界面和截图进入主对话。用哪种由 Agent 根据任务决定。
详情
1
执行模型只操作、只陈述事实
报告分“做了什么 / 看到的事实 / 未完成”，不评价好坏，不替 Agent 做决定；任务明确问它的意见时，才在最后单列“执行模型的看法”。
2
截图作为证据交给 Agent
执行模型的每张截图都自动编号保存，不多花一轮往返；报告在事实旁注明编号（#3）。被引用的原图按“回传截图”的数量随结果附上，全部截图存在临时目录，Agent 可按路径打开。
3
Agent 自己下结论，可以接着指挥
每次委托返回一个 session_id，Agent 带上它再调用，执行模型在原来的画面上继续（“再往下滚”“放大截一张”），闲置 30 分钟失效。Agent 也可以用 look 只看一眼当前屏幕。
详情
1
Agent 拿到 ChatGPT 原版的 js / js_reset
与 ChatGPT 中的 Computer Use 完全相同：Agent 写一段 JavaScript 调用运行时的 API，一段代码可以连做多步（读界面、点击、输入、截图）。
2
每一步由 Agent 自己决定
用的是 Agent 自己的模型，界面树和截图直接进入 Agent 的对话，不用执行模型。
3
没有报告和证据
没有事实报告、证据截图和 session_id。适合 Agent 本身擅长操作电脑，或需要它全程盯着每一步的场景。
执行模型
默认模型
Agent 调用时传入 model 可临时改用其他模型
推理强度
越高越仔细、越慢、越贵；Auto 不指定，用模型与供应商的默认值
最多步数
一次任务最多的模型轮数，1–200
回传截图
每次委托最多把几张证据原图直接交给 Agent，0–10；其余只给文件路径，Agent 需要时再打开

执行模型经 magpie 网关调用，上游用哪种接口由 magpie 中该模型的供应商设置决定。GPT 模型（例如 Terra）建议在供应商里把接口设为 OpenAI Responses：推理内容能在步骤之间延续，提示缓存也能生效。实测 10 个桌面任务，比转成 Chat Completions 快约 4 倍、费用约为 1/3。改完供应商设置后需重启 magpie 才生效。

浏览器
使用 Chrome 扩展操作网页
开启后，执行模型和 Agent 拿到 ChatGPT 原版的浏览器 API，直接打开和操作 Chrome 标签页，不用把 Chrome 当普通应用一点点点击。需要 Chrome 里装有 ChatGPT 扩展；MCU 会把扩展的连接改为经 LCU（lcu browser install），ChatGPT 应用自己的 Chrome 功能照常可用
应用授权

修改工具后，需要在 Agent 中重连本插件的 MCP 或新开会话，工具列表才会更新；其他设置下一次调用即生效。
